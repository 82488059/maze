# maze

迷宫生成与寻路算法的 Python 演示集合。

## 算法示例

- 生成：`prim_maze.py`、`kruskal_maze.py`、`wilson_maze.py`、`aldous_broder_maze.py`、`depth_maze.py`、`multipath.py`
- 寻路：`depth_pathfinding.py`、`sample_pathfinding.py`
- 各 `*_demo.py` 为可视化/演示入口

## 运行

```bash
python prim_maze_demo.py
```

需要 Python 3；部分演示可能依赖图形库（以脚本 import 为准）。
